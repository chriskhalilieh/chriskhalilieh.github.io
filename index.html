ESP32 media display

This is a touchscreen Apple Music media screen I made using an ESP32 that displays the album artwork, song progress, and features pause/resume buttons and volume control. I used the macOS automator to start the terminal once the music app is opened so it isn't running in the background constantly.

what i learned: While I did learn a lot about ESP32 and how to use arduino IDE, I learned a lot more about configuring macOS and troubleshooting any issues I had. From automatically starting programs, extracting certain data from my computer, and debugging code, overall I learned a lot from this neat little project.
